# Portfolio

株式を中心とした自分の資産を、ローカルで定期的に見直すためのダッシュボードです。

## 使い方

```bash
npm install
npm run dev   # http://127.0.0.1:3001 (自分の PC からのみアクセス可)
```

1. 「保有を追加」から銘柄を登録する(日本株・投資信託・現金・その他)
2. 「価格を更新して記録」を押すと、日本株の現在値を取得し、その日のスナップショットを保存する
   - 投資信託の基準価額は手入力(編集から更新)
   - 週1回など定期的に押すと「推移」に総資産の変化がたまっていく

## AI による見直し

「AI による見直し」から、見直しレポートの作成と AI への質問ができます。

Claude API は有料(サブスクリプションとは別課金)なので、AI はボタンを押したときだけ呼び出します。定期実行や自動実行はしません。

### 設定

`portfolio/.env.local` を作って API キーを書き、開発サーバーを再起動します(`.env*` は `.gitignore` 済み)。

```
ANTHROPIC_API_KEY=sk-ant-...
# AI_PROVIDER=claude   # 既定。ollama にするとローカル AI(現在はスタブで未実装)
```

### AI に送る内容(マスク)

- **送る**: 資産クラス別・銘柄別の比率(%)、損益率(%)、上位銘柄の集中度、推移の指数(最初の記録 = 100)
- **送らない**: 金額、株数・口数、単価、総資産額、id
- 銘柄名・コードは「銘柄名を送る」をオンにしたときだけ送る。オフなら「銘柄A(業種)」の形にする
- 「送信内容を確認」で、実際に送るテキストをそのまま確認できる

モデルは `claude-opus-5-5`。レポートは `data/portfolio.json` に履歴として保存されます(最大 50 件)。チャットの会話は保存しません。

## データの保存先

- `data/portfolio.json`(`.gitignore` 済み。**コミットしない**)
- 環境変数 `PORTFOLIO_DATA_PATH` で変更できる

## 注意

- 株価は Yahoo Finance の非公式 API から取得しています。仕様変更で取れなくなることがあります(失敗した銘柄は前回値のまま、画面に警告を出します)。
- このアプリは情報の整理を目的としたもので、投資判断の助言ではありません。
