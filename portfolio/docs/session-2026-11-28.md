## 2. アプリの全体像(おさらい)

**自分の PC の中で完結する家計簿アプリ。** 外に出ていくのは「株価の問い合わせ」と「金額を伏せたデータを AI に相談すること」の 2 つだけ。

```text
┌────────────── 自分の PC ──────────────┐
│   ① 画面(ブラウザ)     … お店の窓口  │
│              ▼                         │
│   ② 裏方(サーバー)     … 奥の事務所  │
│              ▼                         │
│   ③ ノート(data/portfolio.json) … 帳簿 │
└──────────┬───────────────┬────────────┘
     株価を聞く      金額を伏せて相談
           ▼               ▼
      Yahoo Finance      Claude(AI)
```

主な設計の理由:

- 資産データを外に出さないため、すべてを自分の PC に置いた
- 外とのやりとりは必ず裏方を通し、AI に送る前に金額・数量・単価を伏せる
- AI は有料なので、ボタンを押したときだけ呼ぶ
- AI への指示は `prompts/*.md` の文章ファイルにした。書き換えてすぐ試せる

## 3. 用語の説明

| 用語 | 一言でいうと | たとえ |
|---|---|---|
| Node.js | JavaScript を PC の上で動かすエンジン。PC に 1 回インストールする | 車のエンジン |
| Next.js | Web アプリ(画面+裏方)を作るための枠組み | 家の工法 |
| React | 画面の部品(表・グラフ・ボタン)を作る道具 | 部品の型 |
| TypeScript(`.ts` / `.tsx`) | JavaScript に「型」というチェックを足した言語。数字の欄に文字を入れる、といった取り違えを動かす前に見つけられる | 家の材料 |
| ESLint | プログラムの書き方をチェックする道具(`npm run lint`) | 文章の校正 |
| Vitest | 動いた結果が正しいかを確かめるテストの道具(`npm test`) | 試食 |
| `package.json` | 必要な部品の一覧と、よく使う操作の呼び名(`npm run build` など) | 説明書兼部品リスト |
| `package-lock.json` | 実際に入った部品のバージョンの正確な記録 | 納品書 |
| `node_modules/` | ダウンロードされた部品の置き場(自動。Git に入れない) | 部品倉庫 |
| `.next/` | `src/` を動かせる形に組み立てたもの(自動。消しても作り直される。起動中は消さない) | 下ごしらえした材料 |

### 道具の重なり方

```text
資産レビュー(src/ の .ts / .tsx) ← TypeScript で書いている
Next.js + React                    ← 枠組み
Node.js                            ← エンジン
Windows
```
