## 説明したこと(学んだこと)

### データシートで見る場所
節番号は版で少しずれることがあるので、見つからなければ `GPIO_IN`、`PADS_BANK0`、`PUE` で検索します。

| 知りたいこと | 場所 |
|---|---|
| ピンの役割の選び方 | 2.19.1、2.19.2 Function Select(F5 が SIO) |
| 入力の設定と値の読み取り | 2.3.1 SIO(`GPIO_OE`、`GPIO_IN`) |
| プルアップなどの電気的な設定 | 2.19.4 Pads、Pad Control - User Bank |
| 内蔵プルアップの抵抗値(50〜80kΩ 程度) | 5章の電気的な仕様 |

2.19.3 Interrupts(割り込み)は課題2で使います。

### `gpio_init` が必要な理由
- `gpio_init` は SDK(Pico 用のライブラリ)の関数名なので、データシートには出てきません。載っているのは、書き込み先のレジスタ(ハードウェアの設定項目)です。
- 電源を入れた直後のピンは、どの機能にもつながっていません(`FUNCSEL` が `0x1f`)。
- `gpio_init` はピンを SIO(プログラムが直接読み書きする窓口)につなぎます(`FUNCSEL` が `5`)。先に入力にして出力値を 0 にし、意図しない出力を防ぎます。
- 確かめるには、`gpio_init(SW1_PIN)` の行で止め、実行前後の `IO_BANK0` → `GPIO14_CTRL` → `FUNCSEL` を比べます。

### プルアップ
- スイッチを押していない間だけ、ピンを High(1)に弱く引っ張る仕掛けです。バネ付きレバーの「バネ」にあたります。
- スイッチにできるのは「GND(0V)につなぐ」か「何にもつながない」だけです。プルアップは、つながないときの値を High に決めます。
- 押すと GND への直接のつながりが勝って Low(0)になり、離すと High に戻ります。
- 抵抗を通して弱くつなぐのは、押したときに 3.3V と GND がショートして大きな電流が流れるのを防ぐためです。
- `sw1_pressed()` は `!gpio_get` で値を反転するので、Low のとき「押された」になります。

### プルアップを消すと LED が点きっぱなしになる理由
- これは故障ではなく、正しい実験結果です。
- GP14 は電源を入れた直後からプルダウン(Low 側に弱く引っ張る設定)が有効で、`gpio_init` では変わりません。押しても離しても Low なので、区別できません。
- `gpio_pull_up` は `PUE`(プルアップ)を 1、`PDE`(プルダウン)を 0 にします。
- 1章のピン説明の表の `Pull-Down` と、レジスタ表の「`PDE` のリセット値が 1」は同じ事実です。

### パッドと GPIO の関係
- パッドは、チップの中と外の境目にある電気的な回路で、ピンごとにあります。
- 信号は「ピン → パッド → 機能の切替 → SIO → プログラム」と届きます。
- パッド(`PADS_BANK0`)はプルアップや入力の有効化などの電気的な設定、機能の切替(`IO_BANK0`)はつなぎ先の設定を担当します。
- GPIO は、これらをまとめた仕組み全体を指すことが多い言葉です。

### 配線と、動かないときの調べ方
- シリアル(Pico からの文字表示)に `02-button: mode=polling` が出なければ、書き込みやシリアルモニターのポート選択を確認します。
- 表示が出る場合は、GP14(19番ピン)と GND をジャンパー線で直接つないだり外したりします。`pressed` / `released` が出れば、スイッチの挿し方が原因です。
- タクトスイッチの足は2本ずつ内部でつながっているため、対角の足を使うのが確実です。
- GND にはブレッドボードの − の列も使えます。ただし、その列を Pico の GND に線でつなぐ必要があります。左右や上下の − は別の列で、途中で分かれている場合もあります。
- `SIO → GPIO_IN` の bit 14 は、プルアップがある正しい状態なら、離すと 1、押すと 0 です。変わらなければ配線を確認します。
- データシートの表の `17` はチップの足の番号です。配線では Pico ボードの番号(GP14 は19番)を使います。
