### 会話サマリーの自動保存
- **流れ**:会話を閉じる → 裏で処理を起動 → あなたと Claude の発言を取り出す → `claude -p` で要約(サブスクを使い、API 料金はかからない) → `<プロジェクト>/docs/sessions/日付-時刻-ID.md` に保存 → そのファイルだけをコミットして push
- **追加・変更したもの**
  - `~/.claude/settings.json`:会話終了時にスクリプトを実行する設定を追加(元の設定は維持)
  - `~/.claude/hooks/session_summary.py`:要約を作る本体
  - `~/.claude/logs/session-summary.log`:動作の記録
- **試した結果**(仮のリポジトリを使用)
  - 要約の作成とコミットは成功
  - 会話を閉じるときの処理は 0.26 秒で戻った
  - 同じ会話を再開して閉じると、同じファイルを上書き
- **作られない場合**:Git で管理していないフォルダでの作業、あなたの発言が 3 回未満の会話、マージ(変更の統合)などの途中
- **注意**:毎回サブスクの利用量を使うため、要約には Sonnet を使用。秘密や金額を書かない指示はあるが、push されるので気になる場合は中身を確認

## 説明したこと(学んだこと)

### アプリの全体像
自分の PC の中で動く、家計簿のようなアプリです。外とのやりとりは、**株価の問い合わせ**と**金額を伏せたデータでの AI への相談**の 2 つです。

```
画面(窓口) ⇄ 裏方(事務所) ⇄ data/portfolio.json(帳簿)
                  ├─ 株価を聞く → Yahoo Finance
                  └─ 金額などを伏せて相談 → Claude
```

### この構成にした理由
- **PC 内で動かし、同じ Wi-Fi の他の機器からは開けない**:資産データを守るため
- **保存は JSON ファイル(文字で書くデータファイル)1 つ**:1 人用なら十分で、コピーでバックアップできる
- **AI への送信は裏方を通す**:金額・数量・単価を必ず伏せ、API キー(AI を使うための鍵)を画面側に渡さないため。銘柄名は設定がオンのときだけ送る
- **AI はボタンを押したときだけ呼ぶ**:知らないうちに利用料や利用量が増えないようにするため
- **AI の呼び出し方を切り替え可能**:API とサブスクを設定で選べる。PC 内で動く AI(Ollama)は、まだ仮の実装
- **AI への指示は `prompts/*.md`**:文章を書き換えれば、次の回答から反映される
- **Next.js を使用**:画面と裏方を 1 つにまとめて作れる。隣の `taskboard/` と同じ構成
- **選ばなかったもの**:クラウドへの設置、データベース、画面から直接 AI を呼ぶ方法、証券会社との自動連携(CSV 取り込みと手入力で対応)

### 図の種類
| 図 | 分かること |
|---|---|
| 構成図 | 部品と、そのつながり(四角は部品、円柱は保存データ、矢印は流れ、大きな枠は場所) |
| シーケンス図 | 誰が何をどの順番でするか |
| ツリー図 | フォルダとファイルの配置 |

### 用語
| 用語 | 説明 |
|---|---|
| Node.js | JavaScript を PC で動かすエンジン。PC にインストールする |
| Next.js | 画面と裏方を作る枠組み |
| React | 表やボタンなど、画面の部品を作る道具 |
| TypeScript | JavaScript に「型」(入るデータの種類の約束)を加えた言語。取り違えを動かす前に見つけやすい |
| `.ts` / `.tsx` | TypeScript のファイル。`.tsx` は画面の部品も書ける |
| ESLint | 書き方の校正ツール。結果が正しいかを確かめるテストが「試食」なら、こちらは「校正」 |
| Tailwind CSS / Vitest | 見た目を整える道具 / テストの道具 |
| `package.json` | アプリの部品リストと、操作の呼び名(`npm test` など)をまとめたファイル |
| `package-lock.json` / `node_modules/` | 入れた部品のバージョンの記録 / 部品の実物 |
| `.next/` | 組み立て(ビルド)後のファイルなどが入る自動作成フォルダ。停止中なら消しても作り直せる。起動中は消さない |

`portfolio/` 直下の設定ファイルは、各ツールがそこを探すため、今の配置で問題ありません。`next-env.d.ts` は自動で作られるので編集不要です。`AGENTS.md` は消さないでください。
